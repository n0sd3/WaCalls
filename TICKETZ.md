# WaCalls para o Ticketz

Este repositório é um fork de [JotaDev66/WaCalls](https://github.com/JotaDev66/WaCalls),
licenciado sob MIT. A licença original foi mantida (ver `LICENSE`).

- Commit-base: `d16a0768`
- Branch deste fork: `ticketz`

## O que o patch adiciona

- Nome do aparelho: a sessão vinculada aparece no WhatsApp com um nome de aparelho configurável.
- Gravação de chamadas em WAV estéreo (um canal para cada ponta).
- Aviso de gravação durante a chamada.
- Ajustes de API/rotas e testes que sustentam esses recursos.

## Uso

O build do Ticketz clona a branch `ticketz` deste fork (a tag `ticketz-1` marca esta versão).
Não há mudanças de licença: o código novo segue a mesma licença MIT.
